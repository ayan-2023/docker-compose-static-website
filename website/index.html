Project Purpose

About This Dashboard

This dashboard is a static frontend created to demonstrate DevOps concepts including cloud infrastructure, containerization, Linux-based deployment, and application delivery workflows.

The application is intentionally lightweight so it can be containerized using Docker and served through Nginx as part of a practical DevOps deployment project.
